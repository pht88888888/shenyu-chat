第一次打开的样子

装之前先看三件事

  1. 下载安装包：用手机浏览器打开下载链接，得到 Shenyu-1.6.7.apk，约 2.7 MB。
  2. 点击安装：系统提示「禁止安装未知应用」时，在弹窗里点「设置」→ 允许当前浏览器安装，再返回继续。
  3. 桌面出现蓝色鲸鱼图标，名字是「深语」，点开即用。

深语和官方 DeepSeek App 可以同时装在一台手机上，图标很像，靠名字区分。

为什么这么小 深语是原生 App，界面和渲染都在本机完成，不像网页套壳那样打包一整个浏览器内核，所以只有 1.5 MB。
装不上怎么办 提示「应用未安装」，通常是旧版本残留：先在设置里卸载旧版深语，再装一次即可。

深语和官方 App 是什么关系

深语官方 DeepSeek App
登录不用账号，填一个官方 API Key手机号 / 微信登录
付费按 token 计费，在开放平台充值免费额度 + 会员
数据存放只在本机，可导出 zip 备份云端同步，换机自动带回
界面按官方界面重做的原生版官方原版

两者互不影响，可以同时装。深语的回答同样由 DeepSeek 官方接口生成，差别只在登录方式与数据存放位置。

Chapter 02

申领官方 API Key

Key 就是你的调用凭证，按量计费；它和官方 App 的会员是两套东西。

2.1 注册并登录开放平台

  1. 手机或电脑浏览器打开 https://platform.deepseek.com。
  2. 用手机号 + 验证码登录；没有账号的话验证完就自动注册好了，不需要单独注册。
  3. 登录后进入控制台，左侧菜单能看到「用量信息」「API keys」「充值」等入口。

2.2 创建 API Key

  1. 左侧点 API keys → 右上角 创建 API key。
  2. 给它起个名字，随便写，比如 shenyu，方便以后区分是哪台设备在用。
  3. 点创建后，页面会弹出一串以 sk- 开头的字符——这就是 Key。
  4. 立刻复制保存。这个弹窗只显示一次，关掉就再也看不到（丢了只能删掉重建）。
Key 等同于密码 拿到 Key 就等于能花你账户里的钱。别发到群里、别贴在公开仓库、别截图外传。怀疑泄露了就在同一页面把它删除，再建一个新的。

2.3 充值与计费

  1. 左侧 充值，按需充一点（支持支付宝 / 微信）。
  2. 调用是按 token 计费，普通聊天一句话通常只花几分钱。
  3. 余额不足时深语会直接报错（HTTP 402），充值后立刻恢复，不用重新填 Key。
App 里的提示含义怎么处理
401 / Key 无效Key 填错、已删除或已失效回控制台复制正确的 Key，重新粘贴，注意别带空格
402 / 余额不足账户没钱了去 platform.deepseek.com 充值，几分钟内到账
429 / 服务器繁忙触发限流或服务端繁忙等一会儿再发，或换个时段

  1. App 里点左上角 ☰ 打开侧栏 → 底部 设置（第一次打开会自动停在这里）。
  2. 切到 数据管理 标签页，找到「API Key」输入框。
  3. 把 sk- 开头的 Key 粘贴进去，点 保存。
  4. 再点 测试连接，显示「连接正常，Key 可用」就说明通了（这一步不花钱）。
  5. 关掉设置，回到对话页，输入框里直接发消息即可。
Key 存在哪 只存在这台手机 App 的本地设置里，不联网同步、也不写进导出的压缩包。换手机要重新填一次。

保存后输入框会显示成一排圆点；想换 Key 就回来重新粘贴。接口地址默认 https://api.deepseek.com，一般不用改。

第一次对话，建议按这个顺序试

  1. 先发一句普通的：比如「你好，用一句话介绍你自己」。能看到文字一个字一个字出来，说明流式通了。
  2. 再试深度思考：点亮输入框下方的 ✦ 深度思考，问一道需要推理的题（例如「9.11 和 9.9 哪个大」），回答上方会出现「已深度思考（用时 N 秒）」，点一下能展开过程。
  3. 最后试智能搜索：点亮 🌐 智能搜索，问一句需要最新信息的问题（例如「本周有什么科技新闻」），回答里会出现「已搜索 N 个网页」，点开可以看到来源链接。
发出去没反应？ 先看界面上有没有红色提示。没有提示但一直转圈，多半是网络问题：换 Wi-Fi / 换个网络再试一次；仍有问题就回到 设置 → 数据管理 点一次「测试连接」，确认 Key 和网络都正常。

重新生成回答下方的 ⟳，会丢掉这一条重新答一遍。
管理会话侧栏里 长按 某条对话可重命名或删除；点行尾的 ⋯ 进入多选，勾选多条后可批量置顶 / 删除，顶部标题会变成「已选择 N 个对话」。
思考与搜索过程回答上方的「已深度思考（用时 N 秒）· 已浏览 N 个页面」是一整块，点一下展开看完整推理；搜索过程中显示「正在搜索「关键词」…」，结束后自动收起，只剩「已浏览 N 个页面」和一排网站图标，点它弹出全部来源、点某条用浏览器打开原文。
会话自动命名发出第一条消息后，侧栏会立刻用问题内容给这条对话命名，之后服务端给出更合适的标题时还会自动更新。
切换回答版本重新生成后回答上方出现 ‹ 2 / 3 ›，可左右切回旧版本，旧回答不会被删。

Chapter 05

历史对话的导出与导入

深语的备份包和官方 App 的导出包是同一个格式，可以互导。

5.1 从官方 App 导出的包，怎么导进深语

  1. 官方 App：我的 → 设置 → 数据管理 → 导出所有历史对话。
  2. 导出完成后会给出一个下载链接（有效期有限，尽快用），用浏览器打开链接把 deepseek_data-日期.zip 下载到手机。
  3. 深语：设置 → 数据管理 → 从链接导入，把官方给的下载链接粘进去点「导入」， 屏幕顶部会显示下载与解压进度（大小、百分比），不用先下载到本地。
  4. 也可以先下载成 zip，再用「导入历史对话 → 上传」选择本地文件，同样有进度提示。包很大（例如 100 MB 以上）时建议直接用「从链接导入」，它会边下边存，不占内存。
  5. 导入完成后会提示「已导入 N 个对话」，返回侧栏就能看到，并按置顶 / 今天 / 昨天 / 7 天内 / 30 天内 / 更早自动分组。

5.2 把深语里的对话导出（备份 / 换机）

  1. 深语：设置 → 数据管理 → 导出所有历史对话 → 下载。
  2. 会生成 deepseek_data-时间.zip 并弹出分享面板，存到网盘、发给自己都行。
  3. 换新手机后，装好深语，用「导入历史对话」把 zip 选进来即可。
导入前先导出 导入会覆盖同一条对话的旧记录，而且不可撤销。动手前先导出一份，至少心里有底。
导出包里有什么 全部对话的文字、思考过程、搜索来源和会话标题。图片只在部分情况下随包带出；API Key 永远不会写进包里，可以放心转发
情况处理
提示「这不是 DeepSeek 导出的历史记录包」选错文件了，必须是官方或深语导出的 deepseek_data-*.zip
提示「用了更新的导出格式」包来自更新版本的官方 App，先升级深语再导入
提示「压缩包是空的或已损坏」没下载完整，删掉重新下载，下载时别切后台断网
导入后图片显示不出来导出包里不一定带原图，只有文字内容属于正常现象
Chapter 06

常见问题与注意事项

遇到问题先对号入座。

6.1 对话相关

现象原因与处理
发送后没反应，或转两下就停先看有没有红色报错：401 是 Key 不对，402 是余额不够，429 是限流。都没有的话换个网络再试。
回答到一半断掉网络中断或服务端中断。点回答下方的 ⟳ 重新生成即可，历史不会丢。
思考过程一直不展开点「已深度思考（用时 N 秒）」那一行就能展开或收起。
麦克风没反应先在系统里允许深语使用麦克风；录音中出现红点即表示正在采集。识别失败会在输入框上方给出原因。
附件发不出去文件太大或类型不被支持。换小一点的文件，或先把图片压缩再发。

6.2 数据相关

现象原因与处理
卸载后对话全没了对话只存在本机 App 私有目录，卸载即删除。重要对话先导出 zip。
换手机后对话不见了同上，深语不联网同步；用导出的 zip 在「导入历史对话」里搬过去。
删了某条对话还能找回吗不能。删除是立即生效的。
清了 App 数据会怎样对话、Key、设置全部清空，等同于刚装好。
导入大备份时提示「下载失败 / 内存不足」1.6.6 起备份是边下边存到临时文件再解析，内存占用很低；若仍然失败，多半是网络中断或手机存储不足，换「从链接导入」重试一次，或先下载 zip 再走「导入历史对话 → 上传」。
App 闪退了设置 → 数据管理 → 崩溃日志，能看到最近几次崩溃的堆栈，点「复制」把内容发给开发者即可定位。

6.3 三条底线

  1. Key 不外传。 截图、录屏、发群里之前先遮住 sk- 那一串。
  2. ZIP 不外传。 导出包里是你全部对话原文，转发前想清楚。
  3. 导入前先导出。 覆盖是不可撤销的，先备一份再动手。
