# 与官方 demo 的逐页对照（1.5.0）

## 参照方法

官方 demo 是 React 项目，`dist/` 已构建产物可直接跑。用 `python3 -m http.server` 起静态服务，再用
无头 Chromium（Playwright 自带，`/root/.cache/ms-playwright/chromium-1255`）以 **390×844 @2x**、移动端 UA、
`localStorage` 注入 API Key 后逐页截图，得到与真机一致的渲染结果。截图放在
`http://38.55.156.105:8899/ref/`，源码在 `/root/work/deepseek-chat-demo-apk/.cache/chat-demo/src/`。

截图清单：`01-welcome.png`（首次启动弹设置）、`02-welcome-zh.png`（欢迎页）、`03-sider.png`（侧栏）、
`04-settings-general.png`（通用设置）、`05-settings-data.png`（数据管理）。
