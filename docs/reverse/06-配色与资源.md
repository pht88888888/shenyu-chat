# 配色 / 字体 / 尺寸 / 图标资源清单

## 1. 颜色（`res/values/colors.xml` 与 `values-night`）

官方自有色只有 7 个，其余全是 AppCompat / Material 的默认色（`abc_*`、`*_material_*`），可直接忽略。

| 资源名 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `primary` | `#FF426EFE` | `#FF507BF2` | 品牌主色（按钮、链接、选中态） |
| `splashscreenBackground` | `#FFFFFFFF` | `#FF0F0F0F` | 启动页底色 |
| `call_notification_control_background` | `#14000000` | `#1FFFFFFF` | 通话常驻通知按钮底 |
| `call_notification_control_foreground` | `#FF1F1F1F` | `#FFF2F2F2` | 通话通知图标 |
| `call_notification_control_ripple` | `#1F000000` | `#33FFFFFF` | 通话通知按压 |
| `call_notification_hangup_foreground` | `#FFD93025` | `#FFF25A5A` | 通话通知挂断 |
| `call_notification_label_primary` | `#FF0F0F0F` | `#FFF8F8F8` | 通话通知文字 |

> 界面里真正用到的语义色（`bgBase`、`borderL1/2/3`、`labelPrimary/Secondary/Tertiary/Caption`、
> `bubble`、`selector` 等）全部写在 Compose 代码常量里，不在 XML。已按官方明暗两套取值的观感在
> shenyu-chat 的 `ui/theme/Theme.kt` 里复刻，其中 `brandPrimary` 明暗两套已对齐到上表的官方值。

## 2. 字体

**官方没有引入任何品牌字体。** 依据：

- `res/font/` 目录不存在（解包后既无 `font` 也没有 `font-*` 限定目录）。
- `styles.xml` 里 `android:fontFamily` 只有 `sans-serif-medium`（标题/按钮）与 `sans-serif`（正文），
  都是系统字体。
- `assets/` 下唯一的 TTF 是 `org/scilab/forge/jlatexmath/fonts/**`（30+ 个数学字体，
  `jlm_cmr10`、`jlm_cmsy10` 等），只服务公式渲染，不是 UI 字体。

结论：复刻时不需要打包字体，用系统无衬线体即可；中文渲染跟随系统（华为/小米为鸿蒙/思源系列）。
公式渲染若要 1:1，才需要把 jlatexmath 的那套 TTF 一起带上。

## 3. 尺寸

`res/values/dimens.xml` 里 48 条全部是 AppCompat 的 `abc_*` 与 `tooltip_*`，**没有一条是官方业务尺寸**。
官方的间距、圆角、控件高度都是 Compose 里的字面量 `dp`，所以尺寸只能从两处取：

1. 反编译代码里的常量（`\d+\.dp` 出现在布局调用前）；
2. 实机截图量取（需要设备在线）。

已知并从代码/截图中确认的几处：

| 元素 | 值 |
|---|---|
| 顶栏高度 | 60dp（padding 10/12/10/4） |
| 顶栏标题 | 14sp / 22sp 行高，SemiBold |
| 消息区左右边距 | 16dp |
| 用户气泡圆角 | 22dp，内边距 16dp × 10dp |
| 消息操作条图标 | 20dp |
| 发送按钮 | 34dp 圆形 |
| 侧栏宽 | 300dp（沿用本项目取值，官方为 82% 宽） |
| 设置页顶部圆角 | 24dp |

## 4. 图标

- 解出 **162 个** 自绘矢量（`ic_*.xml`、`logo*`、`splash*`），其中 154 个已入库到
  `app/src/main/res/drawable/`，8 个因内部引用缺失（`ic_color_wechat`、`ic_type_pdf`、`ic_launcher_foreground` 等）未导入。
- `tools/gen_official_icons.py` 把其中 **61 个** 转成 Compose `ImageVector`
  （`ui/base/OfficialIcons.kt`），业务侧通过 `DsIcons` 间接使用，换图标不动业务代码。
- 完整清单见 `02-icon-inventory.txt`。

## 5. 启动页

`SplashScreen` 主题（`styles.xml`）只设了 `windowSplashScreenBackground = @color/splashscreenBackground`
与中间的 `ic_splash_logo`（鲸鱼竖版），没有动画。深色下底色 `#0F0F0F`。
