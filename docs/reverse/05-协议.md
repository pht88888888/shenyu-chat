# 官方 App 接口协议（从 dex 常量池还原）

> 域名：`https://chat.deepseek.com`（另有 `cdn.deepseek.com` 放策略页与埋点脚本）
> 前缀：`/api/v0/`；鉴权 `Authorization: Bearer <token>`（官方为登录态 token，本项目用自己的 API Key）

## 1. 请求头（客户端全局）

| 头 | 含义 |
|---|---|
| `Authorization: Bearer <token>` | 登录态 |
| `x-client-platform` | 平台（android） |
| `x-client-version` | 客户端版本（2.8.0） |
| `x-client-bundle-id` | 包名 |
| `x-client-locale` | 语言 |
| `x-client-timezone-offset` | 时区偏移 |
| `x-device-id` / `x-device-model` | 设备标识 |
| `x-thinking-enabled` | 本轮是否开启深度思考 |
| `x-ds-compression` | 压缩标记 |
| `x-ds-trace-id` / `x-ds-served-by` | 链路追踪 |
| `x-file-size` | 文件上传大小 |
| `X-DS-PoW-Response` / `X-DS-Guest-PoW-Response` / `X-DS-Challenge-Response` / `X-Auth-Block` | 反爬挑战应答 |

## 2. 对话流（核心）

- `POST /api/v0/chat/completion` → `text/event-stream`
- 请求体字段：`chat_session_id`、`parent_message_id`、`prompt`、`ref_file_ids`、`thinking_enabled`、
  `search_enabled`、`preempt`、`model`、`action`、`target`、`message_id`、`session_id`、`stream`、`temperature`、`files`/`file_ids`
- 响应逐行 `data: {...}`，增量结构：

```json
{ "v": <值>, "p": <字段路径>, "o": "APPEND" | "BATCH" | "REPLACE" | "REMOVE" }
```

- 事件/状态常量：`append`、`finish`、`close`、`waiting`、`thinking`、`searching`、`toast`、`error`、
  `fragment`、`status`、`quasi_status`、`search_result`、`title`、`content`
- `quasi_status` 取值含 `none` / `FINISHED`（用于“正在思考 / 正在搜索”这类准状态）
- 配套：`/api/v0/chat/stop_stream`（停止）、`resume_stream`（断线续传）、`continue`（继续生成）、
  `regenerate`（重新生成）、`edit_message`（编辑重发）、`message_feedback`（喜欢/不喜欢）、`status`

## 3. 会话

| 接口 | 用途 |
|---|---|
| `chat_session/create` | 新建 |
| `chat_session/fetch_page` | 分页拉历史（侧栏滚动加载） |
| `chat_session/update_title` | 重命名 |
| `chat_session/update_pinned` / `batch_update_pinned` | 置顶（单条/批量） |
| `chat_session/delete` / `delete_all` | 删除（单条/全部） |

## 4. 文件

`file/upload_file`（分片上传）、`file/fetch_files`（取文件元信息）、`file/fork_file_task`（复制到新会话）。
限制：单文件大小上限、每会话文件数上限、文件 token 占上下文比例上限（文案里是「只能阅读全部文件的 %d%%」）。

## 5. 分享

`share/create`（生成链接）、`share/list`、`share/delete`、`share/content`（读分享内容）、`share/fork`（把分享转成自己的会话）。

## 6. 语音（TTS / ASR / 通话）

- TTS：`chat/tts/`、`chat/tts/voice`、`chat/tts/voices`
- 通话：`call/start`（与 completion 同属需要 PoW 应答的接口集合）
- ASR 在语音输入链路里，客户端录音后上传转写

## 7. 用户 / 客户端配置

`users/login`、`login_by_mobile_sms`、`register`、`create_sms_verification_code`、`check_sms_code`、
`create_email_verification_code`、`current`、`settings`、`update_settings`、`logout`、`logout_all_sessions`、
`one_tap_login`、`oauth/{wechat,google}/…`、`mfa/*`、`unbind`；
客户端配置：`client/settings`、`client/settings/report`、`telemetry`。

## 8. 与我们自建 API 的对应

| 官方 | 本项目 |
|---|---|
| `chat/completion`（SSE 增量） | `POST /anthropic/v1/messages`（SSE，`content_block_delta` 等） |
| `chat/stop_stream` | 关闭流 |
| `chat/regenerate` / `continue` / `edit_message` | 本地重建请求体 |
| `message_feedback` | 本地记录 `Message.feedback` |
| `file/upload_file` | `POST /v1/files` |
| `chat/tts/*` | `/v1/tools/tts` |
| `chat_session/*` | 本地 SQLite |
| PoW / 登录 | 不需要（用自带 Key，额度不受官方账号限制） |

> 官方增量协议（`p`/`o`/`v`）在自建 API 里没有，本项目按 `anthropic` 风格的 `delta` 事件解析；
> 如果以后接官方兼容网关，只需在解析层加一个 `p`/`o` 解释器即可，UI 层不用改。
