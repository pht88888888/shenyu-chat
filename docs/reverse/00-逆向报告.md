## 3. 协议（客户端 ↔ chat.deepseek.com）

### 3.1 接口清单（从 dex 常量池提取，全部为 `/api/v0/…`）

| 域 | 接口 |
|---|---|
| 会话 | `chat_session/create`、`fetch_page`、`update_title`、`update_pinned`、`batch_update_pinned`、`delete`、`delete_all` |
| 对话 | `chat/completion`、`edit_message`、`regenerate`、`continue`、`stop_stream`、`resume_stream`、`history_messages`、`message_feedback`、`status` |
| 反爬 | `chat/create_pow_challenge`（PoW 挑战，官方服务端专用） |
| 文件 | `file/upload_file`、`fetch_files`、`fork_file_task` |
| 分享 | `share/create`、`list`、`delete`、`content`、`fork` |
| TTS | `chat/tts/`、`chat/tts/voice`、`chat/tts/voices` |
| 用户 | `users/login`、`login_by_mobile_sms`、`register`、`current`、`settings`、`update_settings`、`logout`、`one_tap_login`、`oauth/{wechat,google}/…`、`mfa/*` |
| 客户端 | `client/settings`、`client/settings/report`、`telemetry` |

### 3.2 流式协议（关键）

- 传输：HTTP POST + `text/event-stream`，逐行 `data: {...}`
- 增量 payload 字段：`v`（值）、`p`（路径）、`o`（操作符）
- 操作符：`APPEND` / `BATCH` / `REPLACE` / `REMOVE`
- 事件/状态常量：`append`、`finish`、`close`、`waiting`、`thinking`、`searching`、`toast`、`error`、`fragment`、`status`、`quasi_status`、`search_result`、`title`、`content`
- 请求体字段：`chat_session_id`、`parent_message_id`、`prompt`、`ref_file_ids`、`thinking_enabled`、`search_enabled`、`preempt`、`model`、`action`、`target`、`message_id`、`session_id`、`stream`、`temperature`、`files`、`file_ids`

> 本项目走自建 `/anthropic/v1/messages`（demo 同源），不依赖官方账号链路；上表用于**字段命名与交互语义对齐**，以及将来接官方兼容网关时直接复用。

### 3.3 业务限制（从文案反推）

- 单文件超限、总文件数上限、文件 token 占比上限（「只能阅读全部文件的 %d%%」）
- 联网搜索与文件互斥：「请先删除文件再开启联网搜索」「搜索开启时无法发送文件」
- 对话长度上限、消息条数上限、置顶数量上限、分享链接数量上限

## 6. 与 shenyu-chat 的差距

| 维度 | 官方 2.8.0 | shenyu-chat 现状 | 处置 |
|---|---|---|---|
| 图标 | 162 个专用图标 | 仅 2 个 logo 矢量，其余手绘 Path | 导入官方图标，替换 `Icons.kt` |
| 文案 | 722 条，含全部 toast/空态/错误 | 手写，措辞不一致 | 全量对齐 |
| 消息菜单 | 复制/喜欢/不喜欢/修改/分支/重生成/分享/朗读/举报 | 复制/重生成（部分） | 补齐 |
| 会话 | 置顶、多选批量、按时间分组、搜索对话 | 分组有，置顶/多选/搜索缺 | 补齐 |
| 思考块 | 「正在思考」→「已思考（用时 N 秒）」可折叠 | 已有，措辞对齐 | 微调 |
| 搜索块 | 「正在搜索」→「已阅读 N 个网页」+ 来源卡 | 部分 | 补齐措辞与来源卡 |
| 分享 | 生成链接/生成图片/分享到微信 | 无 | 新增 |
| 朗读 TTS | 有 | 无 | 新增（系统 TTS 起步） |
| 语音通话 | 有（orb 动画） | 无 | 低优先 |
| 附件面板 | 相册/拍照/文件/微信文件 | 系统选择器 | 改自绘面板 |
| 主题色 | #426EFE / #507BF2 | 自定 | 对齐 |
