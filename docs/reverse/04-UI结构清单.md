## 2. 主对话页

### 2.1 顶栏

左侧菜单（`ic_menu_outline_24`）→ 抽屉；中部会话标题；右侧「新对话」+ 更多。
会话切换/新建时停止当前朗读。

### 2.2 助手消息结构（自上而下）

1. **思考块**：进行中「正在思考」（`message_thinking`），结束后「已思考（用时 %d 秒）」（`message_think_duration`），
   停止时「已停止」（`message_think_stopped`）；可折叠。
2. **搜索块**：`正在搜索`（`message_searching`）/「搜索 %s」(`message_searching_with_query`) /
   `/ 「搜索中...」`（`message_searching2nd`）；工具态「正在查找“%s”」(`tool_find_wip`)、
   「正在浏览网页」(`message_tool_open_wip`)、「正在阅读」(`message_reading_link`)、「正在分析图片」(`message_reading_image`)；
   结束「已阅读 %d 个网页」(`message_search_result`)、「%d 个网页」(`message_search_summary`)；失败「未搜索到合适的内容」(`message_search_failed`)、「搜索已停止」(`message_searching_stopped`)、
   「联网搜索暂不可用」(`tool_search_failed`)、「查找失败」(`tool_find_failed`)、「浏览失败」(`tool_open_failed`)。
3. **正文**：Markdown（标题/列表/引用/GFM 表格/代码块/公式/mermaid）
4. **附件引用卡**：上传中…(`upload_file_status_uploading`)、已上传(`..._sucess`)、解析失败(`..._failed`)、
   未提取到文字(`..._content_empty`)、可能违反使用规范(`..._content_filter`)；「正在上传」(`uploading`)
5. **底部操作条**：
   - 复制（`message_press_copy`，成功后图标切对勾）
   - 喜欢 / 不喜欢（`message_press_like` / `message_press_dislike`）
   - 重新生成（`message_press_regenerate`）
   - 朗读 / 停止朗读（`read_aloud_start_label` / `read_aloud_stop_label`，朗读中「正在朗读」`reading_aloud`）
   - 继续生成（`message_continue`）
   - 更多：修改（`message_press_edit`）、修改并创建分支（`message_press_edit_to_branch`）、分享（`share`）、举报（`message_press_report`）

### 2.3 用户消息

右对齐浅色气泡，可长按「修改」（`message_press_edit`）、复制。

### 2.4 输入区

- 圆角大框，占位「发消息」
- 附件 `+`（`attach_files`「上传文件」）→ 面板：相册(`upload_panel_album`)、拍照(`upload_panel_camera`)、文件(`upload_panel_file`)、微信文件(`upload_file_menu_we_chat`)
- 开关 chip：深度思考（`message_r1_button`）、智能搜索（`message_search_button`）
- 语音 / 键盘切换（`ic_keyboard_voice_24`），按住说话
- 发送/停止（`ic_send_fill_20` / `ic_stop_fill_20`）
- 互斥规则：开启联网搜索时不能带文件（`hint_message_search_with_file_error`、`file_cannot_with_search_toast`）

### 2.5 消息状态 / 错误提示（官方原文）

| 场景 | 文案 |
|---|---|
| 网络 | 请检查网络后重试（`hint_network_error`） |
| 服务异常 | 当前服务异常，请稍后重试（`hint_server_error`） |
| 频率限制 | 消息发送过于频繁，请稍后重试（`hint_rate_limit_reached`） |
| 空消息 | 发送的信息为空（`hint_prompt_empty`） |
| 对话超长 | 为保证回复质量，对话有长度限制。当前对话已达上限，无法继续回复，请开启新对话。（`hint_click_context_exceed_dialog_description`） |
| 消息数上限 | 消息数量达到上限，请开启新对话（`hint_max_message_count`） |
| 生成中再发 | 请在其他消息生成结束后重试（`hint_last_message_is_w_i_p`） |
| 文件违规 | 图片或文件可能违反使用规范（`completion_ref_file_audit_unsatisfied`） |
| 文件过多 | 上传文件数达到上限，每个对话可上传 %d 个文件（`hint_file_count_limit_exceeded`） |

## 3. 侧栏抽屉

- 删除确认：标题「删除该对话」/「删除选择的 %d 个对话？」，正文「删除后，该对话将不可恢复」+
  「由该对话生成的分享链接也将失效」（`session_delete_*`、`session_batch_delete_*`）

## 5. 分享

- 入口：消息「更多 → 分享」（`share`）+ 分享列表页「我共享的链接」（`share_list_title`）
- 选择消息（可多选，计数「已选 %d 组」`share_select_count_short`），
  不支持分享的消息提示「该消息不支持分享」（`share_content_filter_status_toast`）
- 产物：生成链接（`share_link_copy_button`，成功「分享链接已复制」）、
  **生成图片**（`share_generate_image_button`，「保存图片」`share_image_save_photo`，成功「已保存到相册」；
  过长「选择的消息过长，图片生成失败」）、分享到微信（`share_to_we_chat`）
- 图片底部水印/提示：「回答由 AI 生成，仅供参考」（`share_image_footer_alert_v2`）
- 管理：链接列表「共享于 %s」、删除确认「删除链接后，任何人无法通过该链接访问你分享的对话。」、
  上限「当前对话生成链接数达到上限」

## 6. 语音通话（`call_*`，官方 2.8.0 新增）

- 入口：输入区/首页「打电话」（`call_deep_seek`）
- 通话页：orb 动画 + 状态文案「接通中」(`call_connecting`)、「通话中 %s」(`call_in_progress`)、
  「正在聆听」(`call_listening_hint`)、「正在思考」(`call_thinking`)、「说话或轻触打断」(`call_interrupt_hint`)
- 控件：静音、挂断（`ic_call_hang_up`）、重拨（`ic_call_redial`）、折叠（`ic_call_collapse_vector`）
- 结束：评价浮层「评价本次通话体验」+ 6 个标签（听不清我说话 / 异常挂断或不回复 / 频繁打断我 / 虚假信息 / 没理解我的意思 / 其他）
- 异常：长时间无声「如需继续对话，请重新拨打」、服务异常「服务暂时异常，本次通话已结束，请稍后重新拨打」、
  网络「网络异常，请挂断后重新拨打」、其他设备接通「你已在其他设备上接通电话」

## 7. 其他页面

- **图表预览**（mermaid）：「图表」/「代码」切换、全屏、保存到相册（`mermaid_switch_preview/code`、`mermaid_save`、「已保存到相册」）；空态「图表为空」、失败「渲染失败」、加载「图表生成中...」
- **表格预览**（`TablePreviewActivity`）：宽表格全屏横向查看
- **消息反馈页**：标题「反馈」，标签「没有帮助 / 虚假信息 / 有害/不安全 / 其他」，输入框占位
  「我们想知道你对此回答不满意的原因，你认为更好的回答是什么？」，提交成功「反馈成功」
- **图片裁剪**：`ic_crop_outline_24`、`ic_rotate_left_outline_thin_20`、`ic_lasso_select_outline_24`
- **附件选择面板**：相册 / 拍照 / 文件 / 微信文件；「授权更多可访问图片」(`upload_panel_add_more_photos`)

## 8. 朗读（TTS）

- 状态：开始「朗读」→「正在朗读」→ 停止「停止朗读」
- 自动朗读开关：「已开启自动朗读」/「已关闭自动朗读」(`read_aloud_auto_enabled_toast` / `_disabled_`)
- 音色：`chat/tts/voices`，切换失败「音色切换失败，请稍后重试」，下线「该音色已下线，请选择其他音色」
- 错误：限流「朗读已达今日限额」、语言不支持「当前语言暂不支持朗读，可尝试切换音色」、音量低「当前音量较低，请调高设备音量」
