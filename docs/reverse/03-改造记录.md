# 复刻改造记录（参照官方 com.deepseek.chat 2.8.0）

目标：用逆向拿到的官方资产，把 shenyu-chat 的界面与交互往官方 App 靠。
每一项都注明参照的官方资源/文案 key，便于回溯。

## 第一批（已完成，编译 + release 构建通过）

### 1. 图标体系换成官方资产

- 从 APK 解出 **160 个矢量图标**（`res/drawable*/ic_*.xml`），落入 `app/src/main/res/drawable/`。
- `tools/gen_official_icons.py` 把这批 XML 批量转成 Compose `ImageVector`，生成
  `app/src/main/java/com/shenyu/chat/ui/base/OfficialIcons.kt`（59 个常用图标）。
- `DsIcons` 里 31 个图标改为指向官方资产，业务代码零改动（仍是 `ImageVector` 接口）。

### 2. 品牌色对齐

- 浅色主色 `#3964FE` → **`#426EFE`**（官方 `res/values/colors.xml` 的 `primary`）。
- 深色主色保持 `#5686FE`（官方深色 `primary` 是 `#507BF2`，后续可切）。

### 3. 消息「喜欢 / 不喜欢」（官方 message_press_like / dislike）

- `Message` 新增 `feedback: Int`（0 未评价 / 1 喜欢 / -1 不喜欢），随消息落库。
- `ChatDatabase` v1 → v2，`messages` 表加 `feedback INTEGER NOT NULL DEFAULT 0`，
  `onUpgrade` 里 `ALTER TABLE` 兜底；新增 `updateFeedback()` 做单列更新，避免重写整轮消息。
- `ChatViewModel.setFeedback()`：点同一按钮即取消，写入 DB 并弹官方风格轻提示。
- UI：`MessageList` 底部操作条在「复制」后插入两个按钮，选中态换实心图标 + 品牌色 +
  按压缩放回弹（`Spring.DampingRatioMediumBouncy`）。

### 4. 附件面板（官方 upload_panel_album / camera / file）

- 原实现：点附件直接拉起系统文件选择器。
- 现实现：点附件在输入框内展开三项面板「相册 / 拍照 / 文件」，带展开/收起动画与按压回弹。
  - 相册：`PickMultipleVisualMedia(9)`，最多 9 张
  - 拍照：`TakePicture` + FileProvider（`cacheDir/camera/shot-*.jpg`）
  - 文件：`OpenMultipleDocuments`
- 三路统一走 `addUris()`，保留官方限制：单文件 ≤64MB、每对话 ≤50 个文件；
  超限提示改成官方措辞「单个文件大小超过限制（64MB），请调整后重试」
  「上传文件数达到上限，每个对话可上传 50 个文件」。

## 第二批（已完成）

### 5. 侧栏搜索升级为全文搜索

- 官方 `search_hint`「搜索对话内容...」，是搜正文而不只是标题。
- `ChatDatabase.searchBodySessions(query)`：`SELECT DISTINCT session_id FROM messages WHERE blocks LIKE ? ESCAPE '\'`，
  对 `%`、`_`、`\` 做转义。
- `ChatViewModel.searchBody(query)`：`Job` 取消旧查询避免竞态，结果进 `ChatUiState.bodyMatchIds`。
- 侧栏过滤条件改为「标题命中 ∪ 正文命中」；空态文案对齐官方
  （`session_list_empty_title`「暂无对话」+ `session_list_empty_description`「你与 DeepSeek 的对话\n将展示在这里」；
  无结果用 `search_no_result`「暂未找到结果」）。

### 6. 分享为图片（官方 share_generate_image_button / share_image_save_photo）

- 助手消息整块挂 `rememberGraphicsLayer()`，`drawWithContent` 里 `record{}` + `drawLayer`，
  点操作条的分享图标时 `toImageBitmap()` 取位图。
- `ui/share/ShareImageStore`：Android 10+ 走 `MediaStore`（`Pictures/DeepSeek`，带 `IS_PENDING`），
  更低版本写公共目录再插媒体库。
- 结果提示「已保存到相册」/「保存失败」。
- 已知限制：只截到已绘制区域，超长消息（超出视口）会被裁掉——官方是重新排版渲染，后续可换成离屏绘制。

### 7. 表格全屏预览（官方 TablePreviewActivity）

- 正文表格可点开全屏 Dialog（`usePlatformDefaultWidth = false`），标题「表格」+ 关闭按钮，
  内容横向滚动；正文与预览共用 `TableViewContent`，避免两套渲染逻辑漂移。

### 8. 顶栏与设置页

- 顶栏菜单换成官方 `ic_menu_outline_24`，删掉自绘 `MenuGlyph` 用法。
- 设置-通用新增「关于」组，条目与官方一一对应，链接取自 dex 常量池：
  - 检查更新（显示当前版本，提示「当前已是最新版本」）
  - 帮助与反馈 → `https://static.deepseek.com/faq/index.html`
  - 应用权限 → `.../zh-CN/app-permissions.html`
  - 个人信息收集清单 → `.../zh-CN/collected-personal-information.html`
  - 第三方信息共享清单 → `.../zh-CN/third-party-info-sharing-list.html`
  - 服务协议与隐私政策 → `.../zh-CN/deepseek-terms-of-use.html`

## 第三批（已完成，1.7.1）

### 9. 用户消息长按菜单（官方 message_press_copy / edit / edit_to_branch）

- 长按气泡弹出菜单：**复制** / **修改** / **修改并创建分支**。
- 「修改」= 原来的语义（截断其后的消息重发）。
- 「修改并创建分支」= `ChatViewModel.editMessageAndBranch()`：原回答（含它的历史版本）平铺后重编号 1..n
  作为 `variants`，新回答编号 n+1；回答完后可点 ‹ › 在两条不同问法之间切换。
- 编辑态按钮「取消 / 发送」保留，分支模式只是发送分支不同。

### 10. 语音通话页（官方 call_deep_seek 与 call_* 状态文案）

- 新文件 `ui/voice/CallScreen.kt`：深色渐变全屏 + 中心呼吸圆球（录音放大提速、思考时缓慢呼吸）。
- 交互闭环：点球开始录（16kHz PCM）→ 再点结束 → `/v1/audio/transcriptions` 转写 →
  自动发消息 → 流式结束自动朗读 → 回到聆听。
- 状态文案对齐官方：正在聆听 / 正在识别 / 正在思考 / 说话或轻触打断 / 需要麦克风权限才能通话。
- 底部 静音（`ic_call_live_update_mute`）+ 挂断（`ic_call_hang_up`）圆形按钮；
  挂断会停止朗读与录音。输入区多一个电话入口。
- 官方原版是免提式（VAD 自动断句、打断插话），当前是「点一下说、点一下停」，VAD 待后续补。

### 11. 文案对齐第二批

- 底部提示 → 「内容由 AI 生成，请仔细甄别，并合法使用」（`profile_ai_compliance_footer`）
- 停止徽标 → 「已停止」（`message_think_stopped`）
- 朗读失败 → 「朗读失败，请稍后再试」

- 批量删除 → 「删除选择的 N 个对话？」/「删除后，对话将不可恢复，由该对话生成的分享链接也将失效。」

### 踩坑

- 官方图标多为 stroke 型，按 fill 生成会变成实心黑块。
- 自绘 Canvas 图标的坐标越界会被直接裁掉（气泡尖角第一次就这么没的），半径必须先留白。

- 输入行宽度不足时，第三个按钮会被挤出屏幕而不是换行——先确认是「排列溢出」还是「状态没触发」。
