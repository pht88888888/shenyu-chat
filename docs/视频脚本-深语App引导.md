# 「深语」App 引导视频脚本（口播 + 分镜）

> 用途：引导 DeepSeek 免费版被限额的用户，改用「深语」（1:1 复刻官方 Chat Demo 的原生安卓 App）+ 自己的 DeepSeek API Key。
> 成片建议：横屏 16:9 主版本 90 秒；另附 15 秒竖屏引流版。
> 依据事实（2026-11-15 ~ 11-17 多家媒体与用户反馈，非官方公告）：
> - 部分长对话「超过 7 天不活跃」不再支持继续（也有用户 72 小时就遇到）；
> - 单次输入上限缩短到约 4 万字；
> - 每日对话额度受限，触顶提示「因服务器繁忙，使用额度已达上限」，有人连续用不到 2 小时就触顶；
> - 目前没有统一恢复时间，也**没有**能直接解除免费额度限制的付费方案；
> - 官方 2026-11-13 开源 Chat Demo（GitHub: deepseek-ai/chat-demo），可导入 DeepSeek 网页版导出的历史对话，走 API 继续聊。
>
> ⚠️ 全片口径：**不说「免费无限」「破解额度」**。只说「用自己的 API Key，按量计费，额度与官方 App 分开计算」。额度政策随时会变，以页面弹窗为准。

## 三、拍摄 / 制作清单

**必须准备的画面素材**
1. 官方 App 限额提示录屏或截图（可用真实的，也可用文字卡模拟，**但不要伪造官方公告**）。
2. 深语 App 实拍/录屏：欢迎页、侧栏、设置-通用、设置-数据（填 Key）、深度思考时间线、并行搜索折叠行、公式与代码块、深色模式。
3. 官方 GitHub 仓库页（`deepseek-ai/chat-demo`）滚动镜头。
4. 官方状态页 / 新闻标题页（IT之家 11 月 16 日那条），仅作事实引用。
5. 结束卡：App 图标 + 下载二维码 + 教程 PDF 封面。

**口播节奏**
- 全片语速偏快，句子短；每条限制一拍，留 0.3 秒黑场或字卡切换。
- 「限额」「四万字」「额度独立」「按量计费」四个词加重音。
- 第 6 段（填 Key）是转化点，画面要慢下来、放大手指操作。

**字幕规范**
- 中文简体，白字 + 40% 黑底描边，单行不超过 16 字。
- 数字统一：`4 万字`、`7 天`、`API Key`、`按量计费`。

**合规红线（务必遵守）**
- 不说「免费无限」「破解」「绕过限额」。
- 不暗示与 DeepSeek 官方有合作关系；表述为「复刻官方开源 Chat Demo 的原生 App」。
- 提醒用户 API Key 属于个人凭证，泄露会被他人消耗额度。
- 不承诺具体价格与额度数字（「几块钱能用很久」是口语体感，画面不出现具体价目表）。
